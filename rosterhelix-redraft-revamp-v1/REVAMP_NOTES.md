# RosterHelix interface refresh (prototype)

- Consolidates three decision tools into a single tabbed Decision Center.
- Adds hover feedback, gentle entrance animations, decorative motion and reduced-motion support.
- Makes the existing historical-only methodology more explicit.
- Preserves existing API calls and account behavior.

**Not yet implemented:** true forward-looking injury-aware projections, live depth charts, expected opportunity models, rest-of-season schedule adjustments, positional scarcity and lineup replacement value. Those require additional reliable data sources and backtesting. Do not represent current recent-PPG comparisons as statistically validated recommendations.

**Deployment:** back up your current repository, then upload the package contents at the repository root. Render should redeploy from GitHub. Do not overwrite the persistent database.
