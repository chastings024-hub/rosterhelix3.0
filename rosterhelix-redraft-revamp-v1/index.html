Check data connection

Diagnose NFLverse DNS and download access before starting a multi-season sync. This check does not change your database.

Download historical seasons

Download NFLverse weekly player statistics directly to your local database. This requires an internet connection and may take several minutes. A failed season leaves your existing database unchanged.

If sync fails, try downloading one season first (for example 2024–2024). You can also download the NFLverse weekly CSV manually and upload it below using NFLverse format.

Upload a statistics CSV

Upload a CSV from a trusted source. Imports are merged by season, week, and player ID; reimporting the same game replaces it instead of duplicating it.

The upload is processed by your local Python server. The file is not sent to ChatGPT. Source authenticity is not automatically verified; only upload datasets you trust. A successful import also updates the current-season analytics dataset.

Normalized columns: player_id, player_name, position, recent_team, opponent_team, season, week, fantasy_points_ppr, receptions, receiving_targets, rushing_attempts. Additional stats are supported.

Historical observations are not predictions. For forecasts, trade tools, and model evaluation, open Advanced analysis. Run python server.py locally to activate imports and searches. Player names come from the imported data; they are not independently verified.
